# Task Management Web Application

A modern and responsive Task Management Web Application built using HTML, CSS, and JavaScript. This application allows users to create, update, delete, and track tasks with user authentication and real-time updates.

---

## Features

- User Authentication (Register/Login)
- User Authorization
- Create Tasks
- Update Tasks
- Delete Tasks
- Task Status Tracking
- Search Tasks
- Filter Tasks
- Real-Time Updates
- Responsive Design
- Mobile Friendly UI
- Local Storage Support

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
